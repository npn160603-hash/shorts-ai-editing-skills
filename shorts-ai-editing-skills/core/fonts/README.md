# Font đóng gói kèm

| File | Họ | Giấy phép |
|---|---|---|
| `BeVietnamPro-Bold.ttf` | Be Vietnam Pro, Bold (700) | SIL Open Font License 1.1 — `OFL.txt` |
| `BeVietnamPro-SemiBold.ttf` | Be Vietnam Pro, SemiBold (600) | SIL Open Font License 1.1 — `OFL.txt` |

Nguồn: dự án Be Vietnam Pro (https://github.com/bettergui/BeVietnamPro), lấy từ gói npm `@expo-google-fonts/be-vietnam-pro` 0.4.1. Phủ đủ Latin + toàn bộ khối tiếng Việt (U+1EA0–U+1EF9).

Dùng cho: (1) đo độ rộng chữ thật khi chia dòng phụ đề (`core/lib/sae_fontmetrics.py`), (2) burn ASS bằng `fontsdir=` trỏ vào thư mục này để bản xem trước và bản xuất dùng **cùng một font**.
OFL cho phép dùng, nhúng, phân phối lại kèm phần mềm; không được bán riêng file font.
